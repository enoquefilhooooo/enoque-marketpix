# MarketPIX

Loja virtual simples e personalizável, com produtos, banners rotativos, carrinho e checkout preparado para PIX.

## Objetivo

Criar uma loja própria fácil de administrar, sem a complexidade de um marketplace.

## Estrutura inicial

- `app/` — aplicação web
- `public/` — imagens e arquivos públicos
- `components/` — componentes reutilizáveis
- `data/` — dados iniciais da loja

## Próximos módulos

- Loja responsiva
- Banners rotativos
- Cadastro de produtos
- Carrinho
- Painel administrativo
- Checkout PIX
